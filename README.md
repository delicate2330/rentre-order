# rentre-order — 주문확정 와이어프레임

렌트리 주문확정(주문서) 플로우의 프로토타입입니다. 본인인증을 맨 앞 게이트로 강제해 **타인 명의 계약자의 본인인증 미선행 이탈**을 막는 데 초점을 맞췄습니다.

🔗 데모: https://delicate2330.github.io/rentre-order/

단일 HTML 파일(`index.html`)이며, 모든 동작은 더미 데이터로 시뮬레이션됩니다.

## 화면 구성

본인인증 → 계약자 정보 → 설치 주소 → 결제 정보 → (사업자만) 서류 첨부 → 특약 동의 순으로 진행됩니다.

- **STEP 1 — 회원 본인인증 게이트**: 인증 전에는 명의 선택 영역이 잠겨 있고, 휴대폰 인증을 완료해야만 계약자 유형·명의를 선택할 수 있습니다.
- **STEP 2 — 설치 주소**: 제품 설치 주소 입력.
- **STEP 3 — 월 요금 결제 정보**: 결제 방식에 따라 입력 필드가 전환됩니다.
- **STEP 4 — 사업자 서류 첨부**: 사업자 고객만 노출(개인은 건너뜀). 이메일·사업자등록증·결제수단 사진.
- **STEP 5 — 특약 동의**: 혜택 관련 특약사항 확인 및 동의.

## 핵심 분기 로직

- **휴대폰 본인인증 플로우 (회원·계약자 공용)**: 통신사·이름·생년월일·휴대폰번호 입력 → 인증번호 받기 → 6자리 인증번호 입력(3:00 타이머·재전송) → 완료. 회원 본인인증과 계약자 명의 인증이 동일한 플로우를 사용합니다.
- **본인인증 선행 강제**: 타인 명의로 계약하더라도 회원 본인인증을 먼저 완료해야 명의 선택이 가능합니다. "본인인증 = 회원 본인 / 계약 명의 = 인증 후 선택"으로 개념을 분리해 안내합니다.
- **본인 / 타인 명의**:
  - 본인 명의 — 회원 프로필을 노출. 현금지원금은 본인(회원) 명의 계좌로만 수령.
  - 타인 명의 — 회원 카드에 더해 "계약자 명의 인증" 플로우로 계약자를 추가합니다(언제든 삭제 가능). 현금지원금은 회원·계약자 두 명의로 나눠 수령 가능.
- **개인 / 사업자**: 개인은 STEP 4(사업자 서류)를 건너뛰어 4단계, 사업자는 5단계로 진행됩니다. 진행바·단계 카운터가 자동으로 따라갑니다.
- **결제 방식 분기**: 카드결제 → 카드사·카드번호·만료일·소유자명 / 계좌이체 → 은행·계좌번호·예금주. 선택에 따라 필드가 전환됩니다.
